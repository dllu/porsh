# Local model setup

The Porsche 959 FBX is intentionally not stored in this repository. Download `006_porsche_959_wwc.zip` from [Wire Wheels Club](https://wirewheelsclub.com/models/1987-porsche-959/) and run:

```bash
npm run setup:model -- /path/to/006_porsche_959_wwc.zip
```

This installs the FBX into the Git-ignored `public/models/wwc/` directory. Use and deployment remain subject to the [Wire Wheels Club license](https://wirewheelsclub.com/license/).
